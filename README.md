# 💱 Currency Converter (Python)

## 🧠 Project Overview
This is a simple Python-based currency converter developed during my early learning phase. The project reads currency exchange rates from a text file and allows users to convert an amount from INR to various global currencies.

This project helped me understand basic Python concepts like file handling, dictionaries, and user input.

---

## ⚙️ Features

- Convert INR to multiple international currencies
- Reads exchange rates from an external text file
- Simple command-line interface
- Displays available currency options dynamically

---

## 📁 Dataset / File Information

- `CurrencyData.txt` contains:
  - Currency names
  - Exchange rates

---

## 🛠️ Technologies Used

- Python (Core Concepts)
  - File Handling
  - Dictionaries
  - Loops
  - User Input

---

## ▶️ How to Run

1. Make sure both files are in the same folder:
   - `Currency converter.py`
   - `CurrencyData.txt`

2. Run the Python script:
python "Currency converter.py"


3. Enter:
   - Amount in INR
   - Target currency (from given list)
